## Context

Every package written after this one — the store (#5), the publish path (#7), the delivery engine
(#9–#12), the HTTP surface (#14), the event pipeline (#19) and the CLI (#23–#26) — depends on four
primitives that must be settled *once*, before feature code exists, because retrofitting any of them
means touching every file:

1. **Message and trace identity.** PLAN.md **D10** picks ULID (`oklog/ulid/v2`): 26-char Crockford
   base32, time-sortable, no ambiguous characters, embedded millisecond timestamp. The id is the
   spine of the product's differentiator — `messq trace <id>` (§8) works because the id is stable
   from publish through redelivery, DLQ copy and redrive (§5.1 T11, D3). `trace_id` is the W3C
   correlation id stamped on the message, echoed on every delivery, carried into the DLQ copy and
   written on every event row (§7, §9.2).
2. **The subject matcher.** Subject syntax is NATS-style (§1.3): dot-separated tokens, `*` matches
   exactly one token, `>` matches one-or-more trailing tokens. It gates publish (`streams.subjects`,
   §4.2), consumer filtering and cursor top-up (§5.1 T1, #9), `--trace-subjects` (§9.3), `peek
   --subject` and `purge --subject` (§7). A matcher bug **silently misroutes messages** and never
   raises an error, so it is a sealed pure function with a native fuzz target differentially tested
   against a naive reference (§11.6).
3. **The Clock seam.** §3.3 makes `internal/queue` a pure function with "no `time.Now()` (a `Clock`
   seam)" — the load-bearing decision that makes property testing (#13), the reference model and
   deterministic timing tests all cheap. §11 forbids `time.Sleep` in tests outright and requires all
   timing to run through `testing/synctest` bubbles or this seam.
4. **The sentinel error set.** #14 must map *every* failure mode exhaustively onto the closed
   machine-code enum of the error envelope (§7), and #23 must map the same set onto the documented
   exit codes (§8). Both need one canonical, enumerable list to iterate in a test.

**Governing PLAN.md sections:** §1.3 (vocabulary and subject syntax), §2 **D10** (ULID), §3.3
(package layout, pure core, Clock seam), §5 (state machine — the clock discipline the deadline
arithmetic depends on), §7 (trace id propagation, error envelope), §9.2/§9.3 (event vocabulary,
`--trace-subjects`), §11 (testing strategy: fuzzing, synctest, no `time.Sleep`), §13 (dependency
budget).

This issue unlocks #5 directly and is a hard prerequisite for everything downstream of it. It is
also the issue where the lint rules configured in #2 (`forbidigo` banning `time.Now` outside the
seam) acquire something to point at.

## Scope

**In scope**

- `internal/subject`: pattern parsing, compilation, matching, pattern sets, and the naming rules for
  subjects, stream names and consumer names; a fuzz target with a committed seed corpus and a naive
  differential reference.
- `internal/id`: the ULID message-id factory (monotonic, concurrency-safe, defined behaviour on
  backwards clock and entropy overflow), W3C trace-id minting, `traceparent` parsing, and strict
  parsers/formatters for both.
- `internal/clock`: the `Clock`/`Timer`/`Ticker` interfaces, the real implementation (the *only*
  place in the tree allowed to call `time.Now` and friends), and a deterministic `Fake` usable from
  every package's tests.
- `internal/errs`: the sentinel error set, a stable `All()` registry for exhaustiveness tests, and
  the small wrapper type that carries the "what to type next" hint (§8's teaching-error format).
- Package doc comments (`doc.go`) stating the normative rules, plus a generated subject truth table
  that `docs/SEMANTICS.md` (#4) embeds so the documented rules cannot drift from the tested ones.
- Enabling the `forbidigo` `time.*` rule from #2 against the new allow-list file, and extending the
  import-layering check from #1 so these leaves stay leaves.

**Out of scope**

- Ack-token minting/parsing (`stream/consumer/seq/attempt/generation`, **D7**) — lands with the
  settle verbs in **#10**; its fuzz target is added in **#33**. This issue only guarantees that
  stream and consumer names cannot contain the `/` separator that grammar relies on.
- The sentinel → HTTP status/machine-code table and the envelope itself — **#14**.
- The sentinel → CLI exit-code table and id abbreviation/rendering (`01J8Z…KQ7`) — **#23**.
- Header extraction and precedence (`Messq-Trace-Id` vs `traceparent` vs minted) on the publish
  path — **#14**; this issue ships the parser only.
- `clock.regression` as an *event* and a Prometheus counter — **#19** and **#21**; this issue exposes
  the hook they subscribe to.
- Subject-pattern subsumption ("does grant `a.>` cover filter `a.b.*`") — explicitly rejected for
  v1.0 by **D12**; not implemented here or anywhere before phase 2.
- The state machine itself, config structs, and stream/consumer CRUD validation beyond name charset
  — **#7**, **#9**.
- Extending the fuzz corpus and the nightly 30-minute fuzz lane — **#33**.

## Design proposal

Everything below is a **proposal and starting point**, not a mandate; the normative parts are the
rules tables and the acceptance criteria.

### Package placement

PLAN.md §3.3 lists the significant packages; these four are pure leaves that sit *below* them and
extend the layout rather than replace it:

```
internal/subject/   subject + name grammar, compiled matcher      (imports: stdlib only)
internal/id/        ULID message ids, W3C trace ids               (imports: stdlib, oklog/ulid/v2,
                                                                            internal/clock)
internal/clock/     Clock/Timer/Ticker seam + System + Fake       (imports: stdlib only)
internal/errs/      sentinel errors + registry                    (imports: stdlib only)
```

A single `internal/messq` package holding all four is an acceptable alternative if the reviewer
prefers fewer packages; the acceptance criteria are written to be indifferent to that choice. What
is *not* negotiable: none of these may import `internal/queue`, `internal/store`, `internal/api`,
`internal/obs`, `internal/cli` or `pkg/client`.

### 1. `internal/subject`

**Normative grammar** (documented in `doc.go`, mirrored into `docs/SEMANTICS.md` by #4):

| # | Rule |
|---|---|
| S1 | A subject is 1–32 tokens joined by `.`; total length ≤ 512 bytes. |
| S2 | Tokens are non-empty. `""`, `"."`, `"a..b"`, `".a"`, `"a."` are invalid. |
| S3 | A literal token may contain any valid UTF-8 except space, tab, any control character, `.`, `*` and `>`. There is no escape mechanism, by design. |
| S4 | Subjects are case-sensitive: `A.b` ≠ `a.b`. |
| S5 | In a *pattern*, `*` is valid only as a complete token and matches exactly one token — never a substring. `foo*`, `f*o` are invalid. |
| S6 | In a *pattern*, `>` is valid only as a complete token and only as the **last** token. `>.a`, `a.>.b`, `foo>` are invalid. |
| S7 | `>` matches **one or more** trailing tokens: `a.>` matches `a.b` and `a.b.c`, but **not** `a`. |
| S8 | The bare pattern `>` matches every valid subject (the default consumer filter `[">"]`, §4.2). |
| S9 | A pattern containing no `>` matches only subjects with exactly the same token count. |
| S10 | A *literal* subject (publish target, `messages.subject`) must contain no `*` and no `>`. |
| S11 | Stream and consumer names: 1–64 bytes, `[A-Za-z0-9_-]` plus `.` for streams only (so `<stream>.dlq` is expressible, **D3**); must not start or end with `.`, must not contain `/` (the ack-token separator, **D7**), must not be `.` or `..`. |

```go
// Package subject implements the NATS-style subject grammar and matcher (PLAN.md §1.3).
// It is a sealed, pure, allocation-free leaf: no I/O, no clock, no globals.
package subject

// Subject is a validated literal subject: no wildcards (rule S10).
type Subject string

// Pattern is a compiled subject filter. The zero value is invalid; use ParsePattern.
type Pattern struct {
	raw    string
	tokens []tok // never nil for a valid pattern
	gt     bool  // last token is ">"
	stars  bool  // contains at least one "*"
}

type tok struct {
	lit  string // "" for wildcards
	kind kind   // kindLit | kindStar | kindGT
}

func ParseSubject(s string) (Subject, error) // rules S1–S4, S10
func ParsePattern(s string) (Pattern, error) // rules S1–S9

func (p Pattern) Match(s string) bool  // s is assumed valid; invalid input never matches
func (p Pattern) String() string       // exactly the input that produced it (round-trips)
func (p Pattern) IsLiteral() bool      // no wildcards; Match reduces to string equality
func (p Pattern) MinTokens() int       // for cheap pre-filters and for the SQL LIKE prefix

// Set is a compiled disjunction: streams.subjects and consumers.filters (PLAN.md §4.2).
type Set struct{ pats []Pattern }

func ParseSet(raw []string) (Set, error) // rejects an empty slice
func (s Set) Match(subj string) bool     // true if any member matches
func (s Set) Strings() []string          // stable order, for JSON round-trip

// Prefix returns the longest literal dot-prefix of the pattern, e.g. "orders.eu." for
// "orders.eu.*.created", or "" if the first token is a wildcard. #9 uses it to narrow the
// messages_subj index scan before matching in Go.
func (p Pattern) Prefix() string

// ValidateStreamName / ValidateConsumerName implement rule S11.
func ValidateStreamName(s string) error
func ValidateConsumerName(s string) error
```

**Matching implementation sketch** — walk the subject with `strings.IndexByte`, never
`strings.Split`, so `Match` allocates nothing on the hot top-up path (#9 calls it once per candidate
message): loop over `p.tokens`, cutting one token off `s` per iteration; a `kindLit` token must
compare equal, a `kindStar` token consumes any one token, and a `kindGT` token returns `true`
**only if at least one token is still unconsumed** (`s != ""` at that branch — this is exactly the
`a.>` vs `a` edge case, rule S7, and it gets its own named test). After the loop, return `s == ""`
so a pattern without `>` cannot match a longer subject (rule S9). A trailing dot leaves an empty
token and must return `false`, never a match.

**Edge cases and how they are handled**

| Input | Result | Note |
|---|---|---|
| `ParsePattern("")` | `ErrEmptySubject` | never treat as "match all" |
| `ParsePattern(">")` | ok, matches any 1+-token subject | default filter |
| `Pattern(">").Match("")` | `false` | the empty subject is not a subject |
| `Pattern("a.>").Match("a")` | `false` | S7; the classic off-by-one |
| `Pattern("a.*").Match("a.")` | `false` | trailing dot ⇒ empty token ⇒ invalid |
| `Pattern("*").Match("a.b")` | `false` | S5 |
| `ParsePattern("foo>")` | `ErrWildcardInToken` | S6 |
| `ParseSubject("a.*")` | `ErrWildcardNotAllowed` | publish target must be literal |
| subject with invalid UTF-8 | `ErrInvalidUTF8` | validated with `utf8.ValidString` |
| subject containing `\x00` or `\n` | `ErrControlChar` | control chars would wreck log/CLI output |
| 33 tokens / 513 bytes | `ErrSubjectTooLong` | invariant I11: every bound is explicit |
| `Match` called with a *pattern* as the subject argument | `false` (no panic) | `*`/`>` are simply literal-compared and never equal a wildcard token |
| duplicate patterns in a `Set` | accepted, deduplicated on compile | keeps `stream.subjects` idempotent under PATCH |

Errors are wrapped sentinels: `fmt.Errorf("subject %q: %w", s, errs.ErrBadSubject)` so #14 maps them
without a second table.

### 2. `internal/id`

```go
// Package id mints and parses the two identifiers messq exposes: the ULID message id
// (PLAN.md D10) and the W3C trace id (PLAN.md §7).
package id

import (
	"crypto/rand"
	"io"
	"sync"
	"time"

	"github.com/oklog/ulid/v2"
)

// MsgID is a 128-bit ULID. Rendered as 26 Crockford base32 characters.
type MsgID = ulid.ULID

// Gen mints message ids. Safe for concurrent use by multiple goroutines.
type Gen struct {
	clk       clock.Clock
	mu        sync.Mutex
	ms        uint64          // last millisecond handed out (never decreases)
	ent       *ulid.MonotonicEntropy
	onRegress func(back time.Duration) // nil by default; wired by #19/#21
}

type Option func(*Gen)

func WithEntropy(r io.Reader) Option              // deterministic ids in golden tests
func WithClockRegressionHook(f func(time.Duration)) Option

func NewGen(clk clock.Clock, opts ...Option) *Gen

// New never fails: publish must not be able to fail for id reasons.
func (g *Gen) New() MsgID
func (g *Gen) NewString() string

func ParseMsgID(s string) (MsgID, error) // ulid.ParseStrict + our error wrapping
```

Mint algorithm (the ULID spec's monotonic factory, with our two policy choices made explicit):

```go
func (g *Gen) New() MsgID {
	g.mu.Lock()
	defer g.mu.Unlock()

	now := ulid.Timestamp(g.clk.Now())
	switch {
	case now > g.ms:
		g.ms = now
	case now < g.ms:
		// POLICY: clock went backwards. Clamp forward — never emit a regressing id —
		// and tell the observer. Refusing to mint would take the daemon down on an
		// NTP step (PLAN §11.4 clock-jump fault family); a slightly optimistic
		// timestamp is the cheaper wrong answer.
		if g.onRegress != nil {
			g.onRegress(time.Duration(g.ms-now) * time.Millisecond)
		}
	}
	for {
		u, err := ulid.New(g.ms, g.ent)
		if err == nil {
			return u
		}
		// POLICY: ErrMonotonicOverflow (2^80 entropy exhausted inside one millisecond).
		// Step to the next millisecond and re-seed rather than returning an error.
		g.ms++
		g.ent = ulid.Monotonic(g.entropySource, 0)
	}
}
```

Notes and edge cases:

- The entropy source is `crypto/rand.Reader` wrapped by `ulid.Monotonic(r, 0)` (inc `0` ⇒ a random
  increment bounded by `math.MaxUint32`, which is what makes ids unguessable *and* monotonic).
  Our own mutex is the serialization point; do not also wrap in `ulid.LockedMonotonicReader` — one
  lock, not two.
- **Overflow is not hypothetical to a fuzz test**: a stub entropy reader that always returns
  `0xFF…` forces `ErrMonotonicOverflow` on the second call in a millisecond. That test pins the
  loop above, and the loop must be bounded (it terminates because `g.ms++` always advances).
- Ordering contract, stated precisely so tests can assert it: *for one `Gen`, if `New()` returns A
  before `New()` returns B (established by the mutex), then `A.Compare(B) < 0`.* Across `Gen`s there
  is no ordering guarantee — the daemon has exactly one.
- `NewGen` takes the `Clock`, so a `Fake` can be wound backwards to test the regression policy
  without `libfaketime`.
- The `node_id` written into `meta` at store creation (#5, §4.2) is a ULID from this package.

**Trace ids** (W3C Trace Context, §7):

```go
// TraceID is a 16-byte W3C trace id, rendered as 32 lowercase hex characters.
type TraceID [16]byte

func NewTraceID(r io.Reader) TraceID          // never all-zero; retries on the degenerate draw

// ok == false means "unparsable — mint a fresh trace id" (never an error to the caller).
func ParseTraceparent(v string) (tid TraceID, parent SpanID, sampled, ok bool)

// Kind classifies a user-supplied identifier so `messq trace <arg>` and
// GET /v1/messages/{id} can accept either form (#20, #24).
type Kind int // KindUnknown | KindMsgID | KindTraceID
func Classify(s string) Kind
```

`ParseTraceparent` rules, each a test vector:

| Input | Result |
|---|---|
| `00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01` | ok, sampled |
| same with flags `00` | ok, not sampled |
| version `ff-…` | **rejected** (forbidden by the spec) |
| version `01-…` with extra `-`-separated fields appended | accepted; parse the first three fields, ignore the rest (forward compatibility) |
| trace id all zeros | rejected |
| parent id all zeros | rejected |
| uppercase hex | rejected (spec requires lowercase) |
| wrong length / missing field / trailing `-` on version `00` | rejected |
| 8 KiB of `-` | rejected without allocating; the fuzz target asserts no panic and bounded time |

### 3. `internal/clock`

```go
// Package clock is the only place in messq that reads the operating-system clock.
// Everything that observes time takes a Clock; everything that *decides* takes `now`
// as a parameter (PLAN.md §3.3: internal/queue is a pure function).
package clock

type Clock interface {
	// Now is the wall clock. Use it for values that are persisted or displayed:
	// published_at, visible_at, event ts, ULID timestamps.
	Now() time.Time

	// Since is monotonic. Use it for in-process durations that must survive an NTP
	// step: long-poll deadlines, the commit window, --exec heartbeats, latency histograms.
	Since(t time.Time) time.Duration

	NewTimer(d time.Duration) Timer
	NewTicker(d time.Duration) Ticker

	// Sleep is context-aware. There is no bare time.Sleep anywhere in the tree.
	Sleep(ctx context.Context, d time.Duration) error
}

type Timer interface {
	C() <-chan time.Time
	Reset(d time.Duration) bool
	Stop() bool
}

type Ticker interface {
	C() <-chan time.Time
	Reset(d time.Duration)
	Stop()
}

// System is the production implementation. system.go is the sole forbidigo allow-list entry.
type System struct{}

// Fake is deterministic and safe for concurrent use. It lives in the non-test build so
// every package's tests can use it without an internal/testutil import cycle.
type Fake struct{ /* mu, now, waiters heap */ }

func NewFake(start time.Time) *Fake
func (f *Fake) Advance(d time.Duration)   // fires due timers in (deadline, seq) order
func (f *Fake) Set(t time.Time)           // MAY move backwards — that is the point
func (f *Fake) BlockUntil(n int)          // wait until n timers/tickers are armed
func (f *Fake) Armed() int
```

**The written rule** (goes in `doc.go` and is repeated in `CONTRIBUTING.md`):

> *Durable* deadlines (`deliveries.visible_at`, `messages.published_at`, `events.ts`) are wall-clock
> Unix milliseconds, because they must survive a restart and be readable in SQL. *In-process* waits
> are monotonic. A forward wall-clock jump therefore makes in-flight deliveries look overdue and the
> sweeper (#11) will redeliver them — that is correct at-least-once behaviour, every such redelivery
> records `reason=timeout`, and the sweeper's per-tick expiry cap keeps it from becoming a stampede.
> A backwards jump delays expiry; it never resurrects a resolved delivery. #32 owns the fault test.

**Choosing between `Fake` and `testing/synctest`** (documented; §11 permits both):

| Situation | Use |
|---|---|
| Goroutine choreography: sweeper tick, long-poll park/wake, group-commit window, `--exec` heartbeat | `synctest.Test` bubble with `clock.System{}` — inside a bubble the real `time` package is already virtualized, and `synctest.Wait()` removes the "has it armed its timer yet?" race |
| A struct you drive step by step (state machine, backoff schedule, id generator) | `clock.NewFake` |
| Time must move **backwards** (clock regression, `doctor` checks) | `clock.NewFake` — synctest cannot do this |
| Anything at all | **never** `time.Sleep` (lint-enforced by #2) |

`Fake` determinism requirements: due timers fire in `(deadline, armed-sequence)` order, never map
order; `Advance` delivers on buffered size-1 channels and does not block on an unread `C()`;
`Advance(0)` fires timers armed for exactly `now`; `Reset` re-inserts with a fresh sequence number;
`Stop` on an already-fired timer returns `false`.

### 4. `internal/errs`

```go
// Package errs holds the closed sentinel set. Adding a sentinel without adding a row to
// the API table (#14) or the exit-code table (#23) breaks those packages' tests.
package errs

var (
	ErrNotFound      = errors.New("not found")
	ErrConflict      = errors.New("already exists")
	ErrBadRequest    = errors.New("invalid request")
	ErrBadSubject    = errors.New("subject is not valid or not accepted by this stream")
	ErrTooLarge      = errors.New("message exceeds max_msg_size")
	ErrStreamFull    = errors.New("stream is at its limit and discard=new")
	ErrFlowControl   = errors.New("max_ack_pending reached")
	ErrStaleAck      = errors.New("stale ack: the message was already redelivered")
	ErrUnknownToken  = errors.New("unknown or malformed ack token")
	ErrWrongGen      = errors.New("token generation is stale; the consumer was reset")
	ErrPaused        = errors.New("consumer is paused")
	ErrDiskFull      = errors.New("insufficient free disk space")
	ErrReadOnly      = errors.New("storage is latched read-only")
	ErrShuttingDown  = errors.New("shutting down")
	ErrUnauthorized  = errors.New("authentication required")
	ErrForbidden     = errors.New("not permitted for this token")
	ErrLocked        = errors.New("data directory is locked by another process")
	ErrSchemaNewer   = errors.New("data directory schema is newer than this binary")
	ErrUnavailable   = errors.New("daemon unreachable")
)

// All returns every sentinel in a stable order. #14 and #23 iterate it; a missing
// mapping fails their tests, which is the whole point of the registry.
func All() []error

// Error is the teaching-error carrier from PLAN.md §8: what happened, and what to type next.
type Error struct {
	Err  error    // sentinel; errors.Is walks through here
	Op   string   // "store.Publish", "api.fetch"
	Msg  string   // human sentence, no payload data, no secrets
	Next []string // suggested next commands, e.g. []string{"messq consumer ls orders"}
}

func (e *Error) Error() string { /* "op: msg" */ }
func (e *Error) Unwrap() error { return e.Err }

func E(sentinel error, op, format string, args ...any) *Error
func WithNext(err error, next ...string) error // attaches/extends Next, preserving Is()
func NextOf(err error) []string
```

Discipline (stated in `doc.go`, checked by review and by the #14/#23 exhaustiveness tests): every
classifiable failure is one of these, wrapped with `%w`; boundaries use `errors.Is`, never string
matching; the daemon never panics for an operational condition.

### Generated documentation artifact

`TestSubjectTruthTable` writes `docs/generated/subject-rules.md` from the same table the unit tests

## Acceptance criteria

- [ ] `internal/subject` implements rules S1–S11; every row of the rules table and every row of the
      edge-case table has a named unit test, and the table is the single source for the generated
      `docs/generated/subject-rules.md`.
- [ ] `Pattern.Match` and `Set.Match` allocate zero bytes: `BenchmarkMatch` and `BenchmarkSetMatch`
      report `0 allocs/op` (asserted in a test via `testing.AllocsPerRun`, not just observed).
- [ ] `Pattern("a.>").Match("a") == false` and `Pattern(">").Match("") == false` — both have
      dedicated named tests.
- [ ] `ParsePattern(p.String()) == p` for every pattern the property test generates (round-trip).
- [ ] `FuzzMatch` differentially compares the compiled matcher against a naive `strings.Split`
      reference and finds zero disagreements over 60 s in PR CI; seed corpus committed under
      `internal/subject/testdata/fuzz/FuzzMatch/`.
- [ ] `FuzzParsePattern` finds zero panics and zero accept/reject disagreements with the reference
      validator over 60 s in PR CI.
- [ ] `ValidateStreamName` rejects names containing `/`, and a test asserts the `<stream>.dlq`
      derived name of every accepted stream name is itself accepted (**D3** requires this).
- [ ] `Gen.New()` has no error return, and 1 000 000 ids minted from a single goroutine are strictly
      increasing lexicographically and unique.
- [ ] 8 goroutines × 100 000 ids from one shared `Gen` are all unique; ids whose mint order is
      established by a shared lock are strictly increasing.
- [ ] Winding the fake clock back 5 s produces ids that still strictly increase and fires the
      clock-regression hook exactly once with a delta of 5 s ± 1 ms.
- [ ] A stub entropy reader that forces `ulid.ErrMonotonicOverflow` causes `New()` to advance one
      millisecond and return a valid, larger id — no error, no panic, no unbounded loop.
- [ ] `ParseTraceparent` satisfies every row of the traceparent vector table, including rejecting
      version `ff`, all-zero ids and uppercase hex, and accepting version `01` with trailing fields.
- [ ] `FuzzParseTraceparent` and `FuzzParseMsgID` run 60 s clean with no panics.
- [ ] `clock.System` is the only file in the repository that references `time.Now`, `time.Since`,
      `time.After`, `time.Tick`, `time.NewTimer`, `time.NewTicker` or `time.Sleep`; the `forbidigo`
      rule from #2 is enabled with exactly that allow-list, and a deliberately added violation in
      another package fails `make lint` (demonstrated in the PR description).
- [ ] `clock.Fake` fires due timers in deterministic `(deadline, sequence)` order across 1 000 runs
      of a shuffled arming order, and `BlockUntil` makes a timer-arming race impossible.
- [ ] A test that exercises the full default backoff schedule (`[1s, 5s, 30s, 2m, 10m]`, ~13 minutes
      of modelled time) completes in under 50 ms of wall time using the seam and/or a synctest
      bubble, with no `time.Sleep` anywhere.
- [ ] `errs.All()` returns every declared sentinel exactly once; a test asserts uniqueness of
      messages, non-empty messages, no trailing punctuation, and that `All()` is stable across runs.
- [ ] `errs.E(...)`/`WithNext(...)` preserve `errors.Is` against the wrapped sentinel, including
      through two levels of `fmt.Errorf("%w")`.
- [ ] Line coverage ≥ 95 % for `internal/subject`, `internal/id` and `internal/errs`, and ≥ 90 % for
      `internal/clock` — floors added to the per-package gate table from #2.
- [ ] The import-layering check fails if any of these four packages imports another `internal/`
      package other than `internal/clock` (which `internal/id` may import).
- [ ] Direct-dependency count is unchanged except for `github.com/oklog/ulid/v2` (§13 budget: ≤ 8).
- [ ] Every package has a `doc.go` whose comment states the normative rules; `go vet` and
      `staticcheck` are clean; all tests pass under `-race`.

## Test plan

Consistent with PLAN.md §11 (`-race` everywhere, no `time.Sleep`, fuzz on every parser, committed
reproduction artifacts, PR CI ≤ 10 min).

**Unit (table-driven)**

- `TestParsePattern` / `TestParseSubject`: one row per rule S1–S10 plus the edge-case table, each
  asserting the exact sentinel returned.

**Property (`pgregory.net/rapid`)**

- `TestMatchProperties`: generators for valid subjects and valid patterns; invariants —
  (a) a literal pattern matches its own subject and nothing else; (b) `>` matches every generated
  subject; (c) a `>`-free pattern only matches equal-token-count subjects; (d) `Set.Match` equals the
  OR over members; (e) `Match` is deterministic and side-effect free; (f) `String()` round-trip.
- `TestIDMonotonic`: random interleavings of "mint", "advance clock", "step clock backwards";
  invariant — the returned sequence is strictly increasing and every id parses back to itself.
- Failfiles committed under `testdata/regressions/` per §11.2's growing-corpus rule.

**Fuzz (native `go test -fuzz`, 60 s per target on PRs; corpus committed; nightly extension in #33)**

- `FuzzParsePattern(s string)` — no panic, no unbounded allocation, `String()` round-trip on accept.
